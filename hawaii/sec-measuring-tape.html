    Activity 1.2 Let’s Build a Measuring Tape (20 min)

    Checklist.

    • Build a measuring tape for Hawaiian measures (kīko’o and poho).
      🔗
    • Relate previous knowledge from students about converting between measurements.
      🔗
    • Anticipate and correct typical conceptual errors when measuring lengths.
      🔗
    🔗
    The main goal in this part is to help students make connections to previous knowledge (about measures), so that they understand that they can apply similar ideas, when making conversions, to the case of Hawaiian measures.
    🔗
    This will also help students learn that they can use the newly learned measures in general ways, by specifying a number before it. So, in the same way they say “8 feet”, they can say “8 poho” to indicate some length (although non-standard).
    🔗
    For this activity, try that students work in groups of 3–4, if possible. They will need to decide “who’s hands/arms” to use as the model, or if they can use all of them. This can lead to the (wanted) discussion about non-standard measurements.
    🔗
    Even if students are familiar with tape measures, anticipate students making important conceptual mistakes. These are good opportunities to bring key concepts about measures in general. In particular:
    • Make sure that students start at 0, which is convenient for a tape measure as start point.
      🔗
    • Make sure that the numbers grow from left to right, for each measure, and that there are no gaps.
      🔗
    • Help students with labeling at the start.
      🔗
    🔗

    Worksheet 1.2.1 Let’s Build a Measuring Tape
    

    We will first analyze a measuring tape that relates inches and centimeters. We will then build a measuring tape that relates kīko’o and poho.
    🔗

    1.

    Use the tape with marks for in and cm to answer the questions.
    🔗
    1. If an object is \(4.5\) in long, how many cm is that?
      🔗
    2. \(6.35\) cm is how many inches?
      🔗
    🔗
    Solution.
    Sample responses (looking at the ruler):
    🔗
    • \(11.43\) cm (or some close value)
      🔗
    • \(2.5\) inches
      🔗
    🔗
    🔗

    2.

    Now build a single measuring tape for kīko’o and poho.
    🔗
    Key principles for building a measuring tape:
    • We start at zero (0).
      🔗
    • Numbers go from left to right.
      🔗
    • Label each time to identify the measure being marked.
      🔗
    🔗
    Instructions:
    • Use the roll (one side) and markers.
      🔗
    • Whose hands will be used?
      🔗
    • Use an edge for kīko’o, the other for poho.
      🔗
    • Draw a 0 mark for both units. Then: 1, 2, 3, …
      🔗
    • No gaps! No overlaps!
      🔗
    🔗
    Answer the following questions:
    🔗
    1. If an object is 4.5 kīko’o long, how many poho is that?
      🔗
    2. 5 poho is equal to how many kīko’o?
      🔗
    🔗
